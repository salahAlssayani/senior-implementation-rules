# قواعد التطوير الرئيسية بمساعدة الذكاء الاصطناعي (ADMR)

**[English](README.md) | العربية**

أشمل نظام قواعد قابل للإنفاذ تم إنشاؤه على الإطلاق للتطوير البرمجي بمساعدة نماذج الذكاء الاصطناعي. عند تثبيته داخل مستودع الكود وجعل أي مساعد برمجي ذكي يقرأه، تُلزم هذه القواعد تنفيذ **كل مهمة بشكل كامل وصحيح وبمستوى المهندس الأقدم** — دون نقص، دون تخطٍّ، ودون ادعاء إنجاز زائف.

**المؤلف:** Kimi (Moonshot AI) — السطر الأول من كل ملف في هذا المستودع هو توقيع المؤلف.

---

## ما الذي يميّز هذا النظام عن غيره

1. **قابل للإنفاذ لا للتمني.** كل قاعدة لها معرّف ثابت، ودرجة شدّة، و*طريقة تحقق ميكانيكية*. القاعدة التي لا يمكن فحصها أمنية؛ كل قاعدة هنا قابلة للفحص.
2. **تعريف صارم لـ"الانتهاء" (Definition of Done).** بوابات رقمية (تغطية الاختبارات، التحليل الساكن، فحص العناصر الميتة، النتائج الأمنية) تحل محل العبارات الغامضة مثل "بلا أخطاء".
3. **نواة محايدة للتقنية + نمط الموائمة (Adapter).** القواعد الأساسية لا تذكر أي تقنية بعينها. كل نظام يضيف ملف موائمة واحد `RULES_HINTS.md` يربط القواعد بتقنياته المحددة.
4. **البقاء عبر الجلسات.** جلسات الذكاء الاصطناعي تنتهي؛ هذه القواعد تضمن استئناف أي جلسة جديدة من النقطة التي توقفت عندها الجلسة السابقة دون فقدان أي سياق.
5. **مدقق آلي.** `validators/validate.py` يفحص البنية والروابط والتوقيعات وسلامة القواعد — شغّله بعد كل مرحلة تنفيذ.

## التثبيت

### الخيار أ: استنساخ Git (يدوي)

```bash
# 1. استنسخ (أو انسخ) مجموعة القواعد داخل مشروعك
git clone <this-repo> .ai-rules        # أو انسخ المجلد يدوياً

# 2. أنشئ ملف موائمة نظامك
cp .ai-rules/adapters/RULES_HINTS.template.md RULES_HINTS.md
#    ← املأ تقنياتك وأوامرك وتقاليد مشروعك

# 3. وجّه مساعدك الذكي إلى ملف الدخول
#    أضف التعليمة التالية إلى ملف تعليمات نموذجك (AGENTS.md / CLAUDE.md /
#    .cursorrules / ما يعادلها في أداتك):
```

> **تعليمات للمساعد الذكي:** قبل أي عمل، اقرأ `ENTRY.md` في جذر المستودع والتزم بكل قاعدة فيه. القواعد في `.ai-rules/` إلزامية. ملف `RULES_HINTS.md` يكيّفها مع هذا النظام. شغّل `.ai-rules/validators/validate.py` بعد كل مرحلة تنفيذ.

```bash
# 4. تحقق
python3 .ai-rules/validators/validate.py .
```

### الخيار ب: npm (يعمل مع ANY نموذج ذكاء اصطناعي — Claude, GPT, Cursor, Gemini, إلخ)

```bash
# التثبيت العالمي
npm install -g @salahalssayani/ai-development-master-rules

# أو تثبيته كاعتماد تطوير في مشروعك
npm install --save-dev @salahalssayani/ai-development-master-rules

# ثم شغّل المثبّت
npx admr-install
# أو: npm run install:rules
# أو: node scripts/admr-install.js
```

المثبّت عبر npm يقوم تلقائياً بـ:
1. نسخ جميع ملفات القواعد إلى `.ai-rules/`
2. إنشاء `RULES_HINTS.md` من القالب
3. إنشاء/تحديث `AGENTS.md` مع كتلة تعليمات الذكاء الاصطناعي
4. إعداد سكريبتات التحقق في `package.json`

> **يعمل مع كل نماذج الذكاء الاصطناعي:** Claude Code, ChatGPT, Cursor, Gemini, Copilot, Windsurf, أو أي مساعد برمجي ذكي آخر — مجلد `.ai-rules/` وكتلة التعليمات في `AGENTS.md` لا يعتمدان على نموذج محدد.

## بنية المستودع

```
ai-dev-rules/
├── ENTRY.md          ← ملف الدخول الرئيسي — الذكاء الاصطناعي يقرأه أولاً
├── RULES.md          ← دليل القواعد الكامل (المعرّفات + الشدة + التحقق)
├── core/             ← العقيدة: "لماذا" خلف كل قاعدة وتفاصيلها
├── templates/        ← قوالب جاهزة لكل مخرَج مطلوب
├── adapters/         ← قالب RULES_HINTS — واحد لكل نظام يتبنى القواعد
└── validators/       ← validate.py — مدقق البنية والسلامة
```

## تشريح القاعدة

| الحقل | المعنى |
|---|---|
| `المعرّف` | معرّف ثابت يُشار إليه للأبد (مثل `SEC-04`). لا تُعاد ترقيمته أبداً. |
| `الشدة` | **CRITICAL** — توقف الإنجاز. **HIGH** — إلزامية؛ الاستثناء يحتاج مبرراً مكتوباً. **MEDIUM** — مطلوبة؛ الانحراف يحتاج ملاحظة. **LOW** — إرشادية. |
| `القاعدة` | المتطلب الإلزامي، موجَّه للمساعد الذكي بصيغة "أنتَ". |
| `التحقق` | كيف يُثبت الامتثال بالضبط — أمر، فحص ملف، مسح آلي، أو اختبار. |

## الإصدارات

تتبع القواعد الصيغة الدلالية SemVer (`MAJOR.MINOR.PATCH`، انظر `VERSION`). كل تغيير يُسجَّل في `CHANGELOG.md`. كل نظام يثبّت رقم إصدار القواعد الذي يتبناه داخل ملف موائمته.
